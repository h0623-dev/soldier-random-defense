# 캐릭터 이름 기획 (2026-11-21, 사용자 요청 — 아직 게임에 넣지 않음)

사용자: "캐릭터마다 이름이 있어야 할 것 같아. 동물들로 변경할 거니 동물과 맞춰 기획해 줘."

## 원칙
- 캐릭터 = **군별 × 병종** 60명. 한 캐릭터는 훈련병에서 원수까지 **같은 이름**으로 진급한다(등급이 올라도 이름은 그대로, 차림만 바뀐다).
- 이름은 **그 군의 동물**에서 나온 느낌 + **그 병종이 하는 일**이 떠오르는 말. 2~3글자, 부르기 쉬운 우리말(의성어·의태어·생김새).
- 60개가 서로 겹치지 않는다. 실제 인물·상표·다른 게임 캐릭터 이름은 쓰지 않는다.
- 전설의 용사 6종은 이미 이름이 있다(강철비·불사조·매의 눈·불바다·동장군·총사령관) — 그대로 둔다.

## 이름 풀이 (몇 가지)
- 육군: 킁킁이 = 냄새로 찾는 수색 · 쫑긋이 = 귀를 세우고 듣는 통신 · 말똥이 = 눈을 말똥말똥 뜬 관측 · 달리 = 달려서 후송
- 해군: 빙글이 = 빙글빙글 도는 레이더 · 돌돌이 = 조타기를 돌리는 조타병 · 성게 = 기뢰 모양 · 뚜뚜 = 소나 소리 · 튜브 = 구조
- 해병대: 덥석이 = 덥석 무는 악어 · 살금이 = 살금살금 수색 · 늪돌이 = 늪에서도 끄떡없는 화생방 · 영차 = 짐을 나르는 상륙지원
- 특공대: 솜발 = 솜방망이 같은 발(의무) · 속닥이 = 조용한 통신 · 한방이 = 저격 · 사뿐이 = 사뿐히 내려앉는 고공침투
- 공군: 삐삐 = 관제 신호 · 매눈이 = 정찰 · 뚝딱이 = 정비 · 구름이 = 수송기
- 의경: 호루 = 호루라기(교통) · 치직이 = 무전 소리 · 찾음이 = 실종수색 · 으뜸이 = 지휘

## 화면에 쓰는 자리 (제안)
- **유닛 카드**: 윗줄 `군별 · 병기 · 계급` 그대로, 아랫줄 큰 글씨를 **이름**으로 하고 옆에 작은 글씨로 병종 — 예: `바둑이` · 보병.
- **전장 이름표**: 지금처럼 `군별 + 계급`(예: 육군 병장). 이름까지 넣으면 칸을 넘친다.
- **조합 도감 · 부대 탭(숙련도) · 결과 화면(최우수 유닛)**: 병종 이름 앞에 이름을 붙인다 — 예: `바둑이 (보병)`.
- 알림: `육군 바둑이 병장 진급!`

## 정해지지 않은 것
- 이름 60개에 대한 사용자 검토(바꾸고 싶은 이름).
- 병종 이름(보병·갑판병 …)을 함께 보일지, 이름만 보일지.
- 동물 그림을 만들 때 이름의 느낌(예: 흰둥이 = 흰 강아지, 누렁이 = 누런 강아지)을 생김새에 반영할지 — 반영하면 같은 군 안에서도 캐릭터가 구분된다.
