# 설계 (v0.1.0)

## 기획서 요약
군인 계급·병기 기반 랜덤 디펜스 / 레퍼런스: 워크래프트3 원피스 랜덤 디펜스 / 100단계 / Play 스토어·스팀 / 광고·재화 충전 수익 / 시작 시 군별 6종 선택.

## 전장
- 적은 사각 이동로를 계속 돈다. 전장의 적이 50명을 넘으면 패배. 10단계마다 보스(55초 제한).
- 안쪽 5×5 칸에 유닛 배치. 사거리가 짧은 유닛은 바깥, 포병·의무는 안쪽이 유리.
- 웨이브는 24초 간격. 3의 배수: 드론(빠름), 5의 배수: 장갑차(단단함), 10의 배수: 보스.

## 유닛 = 계급 × 병과
- 계급: 군 5종은 기획서의 18계급(이등병~원수), 의경은 의경 4계급 + 경찰 11계급 = 15계급(이경~치안총감).
  계급 수가 달라도 최종 계급의 전투력은 같도록 정규화했다.
- 기본 병과 4종: 보(단일 속사) · 포(광역) · 의(주변 아군 공속 증가) · 통(둔화·취약).
- 유닛의 병과는 기본 병과 2칸. 순수 4종 + 혼성 6종 = 군별 10종, 군별로 이름과 병기가 다르다.
- 병기 이름은 계급대(병·부사관 / 장교 / 장성)에 따라 3단계로 바뀐다.

## 조합 규칙
같은 계급 두 유닛 → 한 계급 위 유닛 하나. 재료 병과 4칸을 세어
1. 한 병과가 3칸 이상이면 그 병과의 순수 유닛
2. 아니면 가장 많은 두 병과의 혼성 (동률이면 먼저 고른 유닛 우선)
3. 4칸이 모두 다르면 두 유닛의 주병과끼리 혼성

예) 보병+보병=보병, 보병+포병=박격포병, 박격포병+박격포병=박격포병, 박격포병+보병=보병.

## 히든 계급 (국군 5종: 원사·준위)
정규 계급표(18계급) 밖의 특수 계급. 데이터는 `data.js`의 `MIL_HIDDEN`, 규칙은 `core.js`의 `hiddenRecipe()`·`summon()`.
- **원사** — 히든 조합: 상사 + 상사이고 두 유닛의 병과 4칸이 모두 다를 때(보·포·의·통) 소위 대신 원사가 된다. 주변 150px 아군 공격력 +20%.
- **준위** — 뽑기: 훈련소 기본 계급이 하사~상사일 때 신병 소집 1회당 3%. 주변 150px 아군 사거리 +15%.
- 둘 다 전투력·조합 취급은 소위급(Lv8). 조합 재료로 쓰면 일반 계급(중위)으로 진급하고 능력은 사라진다 → 남겨 둘지 합칠지가 선택.
- 같은 종류의 효과는 겹치지 않고 가장 큰 값만 적용. 자기 자신에게는 적용되지 않는다.
- 도감에는 발견 전까지 "???"로 표시되고, 발견하면 기기에 저장(`meta.found`)된다.
- 의경에는 히든 계급이 아직 없다(`hidden: []`).

## 경제
- 신병 소집: 무작위 순수 병과. 72% 기본 계급, 22% +1계급, 6% +2계급.
- 훈련소 강화: 소집 기본 계급 +1 (최종 계급 4단계 아래까지).
- 전역(판매): 유닛 가치의 40% 환급.
- 영구 강화: 훈장(5단계마다 1개, 완주 +20)으로 공격력·초기 자금·처치 보상 강화. 기기에 저장.

## 군별 특성
육군 포병 계열 공격력 +15% / 해군 사거리 +10% / 해병대 보병 계열 공속 +15% / 특공대 치명타 15% / 공군 광역 범위 +30%·광역 피해 +10% / 의경 둔화 +30%·보상 +10%·공격력 -52%(15계급이라 조합 효율이 높아 보정).

## 구조
`www/js/data.js` 데이터 · `core.js` 규칙(순수 로직) · `render.js` 캔버스 · `main.js` 화면/입력/저장 · `monetize.js` 광고·결제 연결 지점(미연동).
Android는 Capacitor로 `www/`를 감싼다. Steam은 같은 `www/`를 Electron 등으로 감싸는 방식을 예정.

## 화면 자동 맞춤 (`www/js/layout.js`)
앱 실행 시와 화면이 바뀔 때(회전, 폴더블 접기/펴기, 창 크기 변경) 화면 크기를 읽어 다음을 정한다.
- **배율**: CSS 크기는 모두 rem(1rem = 10px × 배율). 세로 배치는 `min(폭/390, 높이/640)`을 0.88~1.6으로, 가로 배치는 `min(높이/520, 폭/800)`을 0.85~1.8로 제한. 하한은 글자가 너무 작아지지 않게, 상한은 태블릿에서 버튼 대신 전장이 커지게 하려는 것.
- **배치**: 폭 > 높이×1.15이면 가로 배치(왼쪽 전장, 오른쪽에 상단바·정보창·버튼), 아니면 세로 배치.
- **전장 크기**: 세로는 `min(폭, 남는 높이)`, 가로는 `min(높이, 폭 − 오른쪽 패널 최소 폭)`. 전장 비율(720:700)은 고정.
- **세로로 긴 화면**: 남는 높이 일부를 버튼·상단바 높이로 돌린다(`--vy`).
- **캔버스 해상도**: 표시 크기 × 기기 픽셀 비율(품질 단계별 상한 2.5 / 1.5 / 1). 프레임 시간이 2.5초 이상 계속 28ms를 넘으면 품질을 한 단계 내린다(느린 기기 자동 조정). 한 번 내린 품질은 그 실행 동안 다시 올리지 않는다.
- 검사: `npm run serve` 후 `node tests/screens.cjs <폴더>` — 23개 화면 크기에서 화면 밖 요소, 가로 스크롤, 정보창 넘침, 칸·버튼·글자 크기를 확인하고 스크린샷을 남긴다.

## 캐릭터 그림 (`www/js/sprites.js`)
그림 파일 없이 코드로 그리는 2등신 캐릭터. 조합 수가 많아(6군별 × 10병과 × 계급) 부품을 조합하는 방식으로 했다.
- 군별 → 군복 색·모자: 육군·해병대 철모, 해군 수병모, 특공대 베레모, 공군 약모, 의경 경찰모.
- 병과 → 장비: 보 소총 / 포 포신 / 의 구급낭 / 통 무전기·안테나. 혼성 병과는 양쪽에 하나씩 든다.
- 계급대(병기 3단계와 같은 구간) → 병·부사관: 기본 모자 / 장교: 정모 / 장성: 금테 정모·견장·카드 오른쪽 위 별.
- 유닛 카드: 병과 색 발판, 왼쪽 위 병과 글자, 아래 계급 이름표(장교 은색·장성 금색 테두리), 히든 계급은 금색 점선.
- 적: 보병, 드론, 장갑차, 지휘 전차(보스). 둔화는 파란 원, 취약은 노란 테.
- 같은 그림은 `sprite()` 캐시에 한 번만 그려 두고 복사한다(화면 배율이 바뀌면 다시 그림).
- 정식 화풍이 정해지면 `drawSoldier()`·`ENEMY_DRAW`만 바꾸거나 이미지 파일로 교체하면 된다.

### 그림 파일 (만화풍, 2026-11-19 적용)
`www/img/manifest.json`에 등록된 그림이 있으면 코드 그림 대신 그림 파일을 쓴다(군별 10병과가 모두 있을 때만). 유닛은 `www/img/units/<군별>_<병과>.webp`, 적은 `www/img/enemy_<종류>.webp`. 원본·지시문은 `art/raw_figma/`, `art/jobs_figma.json`. 다시 만들 때: 원본 교체 → `python3 -I tools/cutout.py <원본 폴더> <출력 폴더>` → 파일을 위 위치로 옮김.

### 유닛 카드 구성 (2026-11-19 보완)
- 세 겹: 카드 뒤(병과 색 발판, 히든 테두리) → 캐릭터(숨쉬기·사격 반동) → 카드 앞(계급장, 이름표).
- 계급장(오른쪽 위): 계급마다 [모양, 개수]. 병 막대 / 부사관 갈매기 / 위관 다이아 / 영관 꽃 / 장성 별. 데이터는 `data.js`의 `MIL_INSIG`, `POLICE_INSIG`, 히든 계급의 `insig`.
- 이름표(아래): 병과 글자(보·포·의·통) + 계급 이름. 테두리 색은 계급대(기본/은/금), 히든은 금색.

## 효과음 (`www/js/sound.js`)
소리 파일 없이 Web Audio로 합성. `core.js`는 사격 때 `g.sfx`에 병과를, 보스 격파 때 `bossdie`를 넣고, `main.js`가 매 프레임 꺼내 재생한다(같은 소리는 최소 간격을 둬 겹치지 않게). 웨이브 시작·보스 등장은 `g.log`를 보고 낸다. 설정은 `meta.mute`.

## 자동 업데이트 (`www/js/update.js`, `www/sw.js`, `tools/make-update.mjs`)
APK를 다시 설치하지 않아도 게임 내용(화면·규칙·그림·소리 = `www/` 전체)을 앱 실행 시 내려받아 바꾼다.
- **흐름**: 앱 실행 → `update-config.json`의 `url`에서 `version.json`을 읽음 → 빌드 번호가 지금 것(앱에 든 것, 이미 받아 둔 것)보다 크면 목록의 파일을 모두 받아 캐시 `srd-live-<빌드>`에 저장 → 아직 게임을 시작하지 않았으면 바로 다시 열고, 게임 중이면 다음 실행부터 적용. `sw.js`(서비스 워커)가 받아 둔 파일을 앱에 든 파일 대신 내준다.
- **인터넷이 없을 때**: 가지고 있는 버전(받아 둔 것 또는 앱에 든 것)으로 그대로 실행.
- **새 APK 설치**: 앱에 든 빌드가 받아 둔 것 이상이면 받아 둔 것을 버린다.
- **고장 난 업데이트**: 받은 버전이 5초 안에 못 뜨거나 지난 실행에서 못 떴으면 버리고 앱에 든 버전으로 복구, 그 빌드는 다시 받지 않는다(`index.html`의 시작 점검, `srd_live_bad`).
- **빌드 번호**: 마지막 커밋 시각(초). `npm run bundle`이 `www/version.json`(앱용, git에는 올리지 않음)과 `dist/update/`(호스팅에 올릴 폴더)를 만든다. APK를 직접 빌드할 때도 `npx cap sync` 전에 `npm run bundle`을 먼저 실행한다.
- **배포**: `.github/workflows/android.yml`이 main push 때 `dist/update`를 Cloudflare Pages에 올린다. 저장소 Secrets `CLOUDFLARE_API_TOKEN`·`CLOUDFLARE_ACCOUNT_ID`, Variables `CF_PAGES_PROJECT`가 있을 때만 동작. 다른 호스팅을 쓰려면 이 단계만 바꾸면 된다(필요 조건: `dist/update` 폴더를 그대로 올리고, 모든 출처에서 받을 수 있게 CORS 허용).
- **자동 업데이트가 안 되는 것**: 앱 껍데기(Android 쪽) 변경 — 앱 ID, 아이콘, 권한, 광고·결제 같은 기기 기능 추가, `sw.js` 자체. 이런 변경은 새 APK(또는 스토어 업데이트)가 필요하다.
- 켜는 법: `www/update-config.json`의 `url`에 호스팅 주소를 넣는다. 비어 있으면 꺼져 있다.

## 전장 모양과 입체 표현 (2026-11-19 변경)
- **전장**: 720×880의 세로로 긴 형태. 이동로는 모서리가 둥근 긴 사각 순환로(60,70)~(660,820), 안쪽에 발판 5×5(가로 간격 100, 세로 간격 124). 지원 범위(`auraRadius`)는 대각선 이웃까지 닿도록 165.
- **입체 표현**(`render.js`): 위에서 비스듬히 내려다본 느낌. 바닥은 두께(옆면)가 있는 진지 바닥판과 발판, 길은 살짝 파인 흙길. 캐릭터는 네모 카드 없이 발판 위에 서 있고(발판보다 크게, 위로 겹침), 아래쪽 줄이 위쪽 줄을 가린다. 발밑에 그림자와 병과 색 띠, 히든 계급은 금빛 원.
- **표시**(`sprites.js`의 `drawTag`): 발 아래 이름표(병과 글자 + 계급), 머리 오른쪽 위 계급장.
- 움직이지 않는 배경은 한 번만 그려 두고 복사한다(`background()`).
- 전장이 길어져 적이 한 바퀴 도는 거리가 늘었다(2360 → 2700). 난이도를 다시 맞춰 `hpGrowth` 1.134 → 1.13.
- **화면 맞춤 보완**(`layout.js`): 세로·가로 배치 중 전장이 더 크게 나오는 쪽을 고른다(Z Fold 펼친 화면은 가로 배치). 세로가 짧은 화면은 정보창을 줄이고 안내 문구를 숨긴다(`#app.short`).

## 전장 구조 다시 만들기 — 발판 덩어리와 꺾이는 길 (2026-11-19, 사용자가 보낸 협타디 화면 기준)
앞의 "전장 모양과 입체 표현"의 사각 순환로를 대체한다. 사용자가 보낸 화면에서 확인한 구조: 길이 격자 바깥을 도는 것이 아니라 **높이가 있는 발판 덩어리들 사이를 꺾이며 지나가고**, 유닛 자리는 **모양이 다른 여러 덩어리**로 나뉜다. 배치를 베끼지 않고 같은 방식의 자체 맵으로 짰다.
- **격자**: 가로 7칸 × 세로 9칸, 칸 100×100, 전장 720×900. 정의는 `core.js` 맨 위의 `ROUTE`(길이 꺾이는 칸), `PADS`(발판), `DECOR`(장식 칸). 그림으로 그린 배치도가 주석에 있다. 맵을 바꾸려면 이 세 배열만 고치면 된다(발판은 합쳐서 25칸 유지).
- **길**: (행0,열0)에서 오른쪽 → 아래 → 왼쪽 → 아래 → 오른쪽 → 아래 → 왼쪽 → 위로 돌아오는 닫힌 길, 길이 3600. 적은 이 길을 계속 돈다(패배 조건은 그대로 50명 초과).
- **발판 덩어리 4개**: 위 5×2(10칸), 왼쪽 세로 1×2(2칸), 가운데 오른쪽 4×2(8칸), 아래 5×1(5칸).
- **그리기**: 발판은 옆면이 보이는 두꺼운 블록(체크 무늬 윗면, 이웃한 칸은 한 덩어리로 이어짐), 길에는 진행 방향 화살표, 빈 칸에는 모래주머니 진지. 캐릭터 크기 84, 발 위치 +34.
- **수치**: 지원 범위 150(옆·위아래·대각선 이웃), 길이 유닛 옆을 여러 번 지나가 화력이 닿는 시간이 늘었으므로 `hpGrowth` 1.13 → 1.137.
