# 협타디 대조 기획안 — 우리 게임에 아직 없는 것 (2026-11-20)

사용자 요청: "협동타워디펜스를 검색하고 정보를 취합하고 영상도 보면서, 지금 개발이 안 된 사항들을 정리해 기획안으로 보고하라."

## 2. 협타디의 구조 (조사 결과)

**전투**
- 2명이 실시간으로 함께 막는다. 맵이 위아래 절반으로 나뉘고 각자 자기 영역에 유닛을 놓으며, 가운데 공통 구역을 함께 지킨다. 솔로, 보스 러시, 1:1 대전(카이저의 결투장)도 있다.
- 적이 중심에 닿으면 생명(하트 5개)이 줄고, 보스는 제한 시간 안에 못 잡으면 진다.
- 유닛 등급 5단계(일반·희귀·영웅·전설·마신) + 초마신. 같은 종류·같은 등급 둘을 합성하면 한 등급 위의 무작위 유닛.
- 초마신은 정해진 전설 유닛 조합과 배치로 만든다. 저마다 고유 기술이 있다(전 맵 공격, 빙판, 골드 비례 공격력, 아군 전체 공속 등).
- 전투 중 자원 두 가지: 골드(소환)와 마석. 마석은 광산 슬라임을 고용해 캐고(예: 31/31마리), 강화·유닛 교환·초월에 쓴다.
- 전투 중 하단 메뉴 4개: 미션(히든 미션 포함) · 현상금 사냥 · 마석 채굴 · 강화.
- 특수 발판: 유물 "바람의 깃발"이 공격 속도 +12.5% 발판을 만든다(날개 발판). 천사 발판도 있다.
- 난이도: 보통 · 어려움(적에게 보호막) · 지옥 · 심연. 최고 웨이브 기록(Best wave 111 등).
- 2배속은 광고나 결제로 시간제 이용. 전투 중 채팅.

**전투 밖(로비)**
- 번개(행동력): 한 판에 5개, 최대 40개 안팎. 계정 레벨, VIP.
- 유닛 수집과 레벨업: 같은 유닛 카드를 모아(예: 9/30) 실버로 올린다. 유닛 스킨.
- 유물: 일반 유물(공격력·치명타·자원·소환) + 초마신 전용 유물, 레벨업과 돌파.
- 뽑기판: 7×7 칸을 티켓으로 뒤집는다. 광고 티켓(하루 3회), 누적 보상(21/50), 연속 뽑기.
- 일일 상점(할인·매진), 스페셜 오퍼, 보상 배율 패키지, 시즌 패스, 이벤트, 퀘스트, 랭킹, 마왕의 문·도전.
- 친구랑 하기, 빠른 시작(매칭).

**이용자 불만(리뷰)**: 고의 방해 유저와 소통 문제, 콘텐츠 부족, 후반(어려움 103단계쯤) 렉과 튕김, 2배속 시간제.

## 4. 제안 — 무엇을 어떤 순서로

원칙: 협타디의 이름·캐릭터·맵·수치를 옮기지 않는다. 구조만 참고하고 군대 소재로 다시 만든다.

### 1단계 — 한 판의 재미 (서버 없이 가능, 먼저 권함)

> **2026-11-20 구현 완료.** 6개 항목 모두 반영했다. 실제 규칙과 수치는 `docs/DESIGN.md`의 "기획안 1단계" — 아래 표는 제안 당시의 내용이라 구현과 다른 부분이 있다(용사는 군별 구분 없이 6종 공통, 유니크 등급에서 탄생, 종류마다 한 명).

| 번호 | 제안 | 협타디의 대응 | 내용 | 규모 |
|---|---|---|---|---|
| 1-1 | **전설의 용사** | 초마신 | 군별 6~8종. 전설·초월 등급에서 정해진 병과 조합으로 탄생. 고유 기술 하나씩(예: 전 맵 포격, 빙결 지대, 군자금 비례 공격력, 아군 전체 공속, 처치 시 군자금). 도감에 조합식과 발견 기록 | 큼 |
| 1-2 | **특수 발판** | 날개·천사 발판 | 판마다 발판 2~3칸이 무작위로 특수 발판이 된다(공속 +, 사거리 +, 치명타 +). 어디에 누구를 세울지가 전략이 된다 | 작음 |
| 1-3 | **보급 기지(투자)** | 광산 슬라임 | 군자금으로 보급병을 고용하면 일정 시간마다 군자금·보급품이 들어온다. 지금 쓸지 투자할지 고르게 된다. 주둔지에 건물로 넣기 좋다 | 중간 |
| 1-4 | **병과 교체** | 유닛 교환 | 보급품을 써서 고른 유닛의 병과를 다시 뽑는다(등급 유지). 조합이 무작위가 된 지금 규칙에 꼭 필요한 보완 | 작음 |
| 1-5 | **히든 임무** | 히든 미션 | 조건이 숨겨진 임무 5~6개(예: 한 병과로 발판 채우기). 달성하면 큰 보상 | 작음 |
| 1-6 | **병과 고유 기술** | 유닛별 기술 | 특수 병과 6종에 작은 고유 효과(저격 = 치명타, 화생방 = 지속 피해 지대 등). 지금은 능력치만 섞임 | 중간 |

### 2단계 — 다시 하게 만드는 것 (서버 없이 가능)

| 번호 | 제안 | 협타디의 대응 | 내용 | 규모 |
|---|---|---|---|---|
| 2-1 | **병과 숙련도** | 유닛 레벨업 | 판이 끝나면 쓴 병과의 경험치가 쌓여 그 병과가 영구히 조금 강해진다. 60개 병과가 수집·육성 대상이 된다 | 중간 |
| 2-2 | **부대 표창(유물)** | 유물 | 전체에 적용되는 영구 효과 15~20개(공격력, 소집 할인, 특수 발판 추가, 보급 기지 효율…). 군별 전용 표창. 훈장이나 뽑기로 얻고 올린다 | 큼 |
| 2-3 | **새 모드 2개** | 보스 러시, Best wave | ① 보스 러시(보스 10종 연속) ② 무한 모드(100단계 이후 끝없이, 최고 기록) | 중간 |
| 2-4 | **작전 본부(로비)** | 로비 | 처음 화면을 본부로: 출석 보상, 일일 임무 3개, 군별 최고 기록, 표창·숙련도 화면 | 중간 |
| 2-5 | **보급 뽑기판** | 뽑기판 | 판을 하면 얻는 티켓으로 칸을 뒤집어 훈장·표창 조각을 얻는다. 결제 없이도 돌아가게 설계하고, 결제 연결은 3단계에서 결정 | 중간 |

### 3단계 — 사용자 결정이 먼저 필요한 것

| 번호 | 항목 | 결정할 것 |
|---|---|---|
| 3-1 | **2인 협동** (협타디의 정체성) | 서버가 필요하다(실시간 동기화, 매칭, 방해 유저 대응). 비용과 운영 부담이 생긴다. 넣을지, 넣는다면 1차 출시 뒤로 미룰지 |
| 3-2 | **랭킹·친구·채팅** | 서버와 계정이 필요하다. 3-1과 묶어 결정 |
| 3-3 | **광고·결제** | 보상형 광고(2배속, 티켓, 훈장), 인앱 결제(광고 제거, 패스). 확률형 아이템을 팔면 확률 표시 의무가 생긴다. 무엇을 팔지, 뽑기를 유료로 할지 |
| 3-4 | **행동력(번개)** | 하루 플레이 횟수를 제한하는 장치. 결제 유도용이라 호불호가 갈린다. 넣을지 |
| 3-5 | **스킨** | 그림 비용이 든다. 수익화와 함께 결정 |

### 권하는 순서

1. **1-4 병과 교체, 1-2 특수 발판, 1-5 히든 임무** — 작고 효과가 바로 보인다.
2. **1-3 보급 기지, 1-1 전설의 용사** — 한 판의 깊이를 만든다. 전설의 용사는 그림이 필요하다(군별 6~8장 × 대기·공격).
3. **2-1 숙련도, 2-3 새 모드, 2-4 본부** — 출시 전에 "계속 할 이유"를 갖춘다.
4. 3단계는 결정에 따라.

협타디 리뷰에서 반복되는 불만(방해 유저, 후반 렉, 시간제 2배속)은 우리가 피할 수 있는 지점이다. 혼자서도 완결되는 게임으로 먼저 내고, 2배속은 기본 제공으로 두는 쪽을 권한다.
