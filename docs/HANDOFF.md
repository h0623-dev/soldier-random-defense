## 2026-11-19 — 만화풍 캐릭터 시도 (그림 생성 한도로 중단)
**사용자 요청**: 캐릭터를 만화(소년만화) 그림체로.
**직접 한 작업**
- Hugging Face Z-Image-Turbo로 만화풍 캐릭터 생성을 시도. 64장(군별 10병과 × 6 + 적 4) 중 **7장만 생성**되고 무료 ZeroGPU 일일 한도(계정 GAKSU)가 소진됨. 생성된 것: army_inf, army_art, navy_inf, navy_art, marine_inf, marine_art, sf_art.
- 원본은 `art/raw/`, 전체 프롬프트 목록은 `art/jobs.json`(seed 7, 1024×1024, steps 8). 이어서 만들 때 그대로 쓰면 같은 그림체가 나온다.
- `tools/cutout.py`: 흰 배경을 지워 투명 배경 256px webp로 만드는 스크립트(7장으로 확인).
- 게임 쪽 준비: `www/img/manifest.json`에 적힌 그림을 불러와 유닛·적에 쓰는 코드 추가(`sprites.js`의 `loadArt`). 군별 10병과가 모두 있는 군별만 그림 파일을 쓰고 아니면 코드 그림을 쓴다. 지금 manifest는 비어 있어 **게임 화면은 이전(코드 그림)과 같다.**
**남은 일 / 주의**
- 나머지 57장 생성 필요. 무료 한도로는 하루 몇 장뿐이라 PRO 구독(사용자 결정) 또는 다른 생성 수단이 필요.
- navy 2장은 얼굴·머리 모양이 기존 유명 만화 캐릭터와 닮게 나왔다 → 쓰지 말고 프롬프트를 바꿔 다시 만들 것. 출시 전 모든 생성 그림을 같은 관점에서 검수해야 한다.
- 그림 파일은 계급대(장교·장성)별 차림이 없다. 계급은 이름표·테두리·별로만 구분된다.
- 완성 후 절차: `python3 -I tools/cutout.py art/raw www/img/units` → 적 4장은 `www/img/`로 옮김 → `manifest.json`에 `"units/army_inf"`, `"enemy_boss"` 형식으로 나열.

**실기기 확인(사용자)**

**직접 한 작업**

- 작업 환경을 `soldier-random-defense` 전용 환경(dl.google.com 허용)으로 옮겨 APK를 직접 빌드해 사용자에게 전달. 빌드: `/opt/android-sdk`에 cmdline-tools → `sdkmanager "platform-tools" "platforms;android-36" "build-tools;36.0.0"` → `ANDROID_HOME` 지정 후 `./gradlew assembleDebug`. Maven Central이 429를 줄 때가 있어 재시도 필요.
**검사**

**남은 한계**

- 움직임(사격 동작, 걷기)·효과음 없음. 도감·군별 선택 화면에는 아직 캐릭터가 나오지 않는다.
- 캐릭터가 들어간 화면은 실제 기기에서 아직 확인되지 않았다.
