# 인게임 화면 UI 시안 5종 (2026-11-20)

사용자 요청: "게임 화면이 잘 보여야 하는데 버튼이 너무 많아 잘 안 보인다. 여러 랜덤 디펜스 게임을 참고해 뻔하지 않은 기획 시안 5개를 보여 달라."

- `ui-concepts.jpg` — 현재 화면 + 시안 A~E, 윗줄은 평소 화면, 아랫줄은 유닛을 골랐을 때.
- `index.html` — 시안을 그린 페이지. 같은 폴더에 `js`, `img`, `style.css`(저장소의 `www/` 것)를 두거나 링크를 걸고 웹 서버로 열면 다시 볼 수 있다.

| 시안 | 참고 | 핵심 |
|---|---|---|
| A. 원버튼 | 랜덤다이스 · 운빨존많겜 | 큰 소집 버튼 하나 + 병과 강화 4칸. 나머지는 ≡ 안으로 |
| B. 엄지 휠 | 모바일 액션 게임의 스킬 휠 | 소집 버튼 하나, 위로 밀면 부채꼴 메뉴. 유닛을 누르면 둘레에 고리 메뉴 |
| C. 지휘 카드 | 워크래프트 랜덤 디펜스 유즈맵 | 아래 6칸이 선택에 따라 바뀜 |
| D. 작전 카드 | 러시 로얄 · 카드 손패 | 지금 살 수 있는 것만 카드로 들어옴 |
| E. 주둔지 | 협타디의 맵 오브젝트 | 버튼이 전장 아래 주둔지의 건물이 됨 |

공통: 상단바를 2줄에서 1줄로, 배경을 화면 끝까지 이어 전장이 화면 전체처럼 보이게.
결정 대기 중. 아직 게임에는 적용하지 않았다.
