# 군인 랜덤 디펜스 — 다른 AI로 캐릭터 그림 만들기

육군은 계급대별 그림(40장)이 이미 게임에 들어가 있습니다. 나머지 5개 군별의 계급대별 그림 **190장**이 필요합니다.

| 군별 | 장수 | 계급대 |
|---|---|---|
| 해군 navy | 40 | t1 부사관 · t2 위관 · t3 영관 · t4 장성 |
| 해병대 marine | 40 | t1 · t2 · t3 · t4 |
| 특공대 sf | 40 | t1 · t2 · t3 · t4 |
| 공군 air | 40 | t1 · t2 · t3 · t4 |
| 의경 police | 30 | t1 · t3 · t4 (의경 계급에는 t2가 없음) |

한 계급대는 병과 10종(기본 4 + 조합 6)이라 10장씩입니다. 병·이병급(기본 그림)은 이미 있어서 만들지 않습니다.

## 이 묶음에 든 파일

| 파일 | 쓰임 |
|---|---|
| `01_common_instruction.txt` | **다른 AI에 맨 처음 붙여 넣는 공통 지시문** (영어) |
| `by_branch/navy.md` 등 5개 | 군별로 나눈 **그림별 지시문** — 파일 이름과 지시문이 한 쌍씩 |
| `prompts.md` | 위 5개를 합친 전체본 |
| `prompts.csv` | 엑셀에서 열어 진행 상황을 체크하기 좋은 표 (파일 이름·군별·병과·계급대·지시문) |
| `prompts.json` | 자동화 도구용 (파일 이름 → 지시문) |
| `checklist.txt` | 만들어야 할 파일 이름 190개 목록 |
| `reference/01_style_and_rank_tiers_army.jpg` | **그림체 기준** + 계급대마다 달라지는 정도 (항상 첨부) |
| `reference/02_navy_base.jpg` ~ `06_police_base.jpg` | 그 군별의 기존 기본 그림 — 색과 장비 모양 기준 (작업하는 군별 것만 첨부) |
| `reference/single_army_inf*.png` | 낱장 견본 5장 (참고 그림을 1장씩만 받는 AI용) |

## 하는 순서

1. 그림 AI에서 **새 대화**를 엽니다.
2. `reference/01_style_and_rank_tiers_army.jpg`와 작업할 군별의 참고 그림(예: 해군이면 `02_navy_base.jpg`)을 첨부합니다.
3. `01_common_instruction.txt` 내용을 통째로 붙여 넣고 보냅니다.
4. `by_branch/<군별>.md`를 열어, 회색 상자 안의 영어 지시문을 **하나씩** 붙여 넣습니다. (지시문 1개 = 그림 1장)
5. 나온 그림을 그 지시문 위에 적힌 **파일 이름 그대로** 저장합니다. 예: `navy_inf_t1.png`
6. 한 계급대(10장)가 끝나면 새 대화를 열어 2번부터 다시 합니다. 한 대화에 너무 많이 만들면 그림체가 흐트러집니다.

Midjourney처럼 대화형이 아닌 도구는 참고 그림을 "스타일 참조"로 넣고 지시문만 한 줄씩 돌리면 됩니다.

## 그림 규격 (받을 때 확인)

- 정사각형 1024×1024 이상, PNG 권장 (JPG·WebP도 처리 가능)
- 캐릭터 1명, 머리부터 발끝까지 전부 보이고 잘린 곳 없음
- 배경은 **순수한 흰색** 또는 투명. 바닥 그림자·배경 그림·글자·서명·테두리 없음
- 2등신, 굵은 검은 외곽선, 평평한 색 — 참고 그림과 같은 그림체
- **실제 군·경찰 휘장, 부대 마크, 국기, 옷 위 글자 없음**
- 기존 만화·게임 캐릭터와 닮지 않을 것
- 같은 계급대 10장은 얼굴·모자·옷이 같고 손에 든 장비만 다를 것

다시 만들어야 하는 경우: 손이나 발이 잘림 / 캐릭터가 2명 / 배경에 색이나 그림자 / 모자에 실제 휘장처럼 보이는 무늬 / 글자가 들어감 / 그림체가 사실적으로 변함.

## 파일 이름 규칙

`<군별>_<병과>_t<계급대>.png`

- 군별: `navy` 해군, `marine` 해병대, `sf` 특공대, `air` 공군, `police` 의경
- 병과: `inf` `art` `med` `sig` (기본) / `inf-art` `inf-med` `inf-sig` `art-med` `art-sig` `med-sig` (조합)
- 계급대: `t1` 부사관급, `t2` 위관급, `t3` 영관급, `t4` 장성급

이름이 틀리면 게임이 그 그림을 찾지 못하므로 지시문 위에 적힌 이름을 그대로 복사해 쓰세요.

## 돌려주는 방법

- 만든 그림을 한 폴더에 모아 zip으로 묶어 Claude Code 대화에 올리면 됩니다.
- 190장을 한 번에 다 만들 필요 없습니다. **군별 하나, 계급대 하나만 끝나도** 올려 주면 그만큼만 먼저 게임에 넣습니다. 없는 그림은 아래 계급대 그림이 대신 나옵니다.
- 용량이 크면 군별로 나눠 올리거나, 저장소의 `art/incoming/` 폴더에 넣어 GitHub에 올려도 됩니다.

받은 뒤 배경 지우기, 크기 맞추기(256px webp), 게임 적용, 배포는 Claude Code가 합니다.

## 알아 둘 점

- 참고 그림 중 `navy_med-sig`(해군 항공)의 어깨 패치는 따라 그리지 않도록 공통 지시문에서 국기를 금지했습니다.
- 지시문의 "Korean navy ..." 같은 표현은 분위기를 정하기 위한 것이고, 실제 휘장을 그리라는 뜻이 아닙니다.
- 지시문을 고치고 싶으면 얼굴·옷 부분은 같은 계급대 10장에 똑같이 고쳐야 그림이 서로 맞습니다.
