# 젠스파크(또는 다른 그림 AI)로 남은 그림 만들기

Figma 하루 한도 때문에 못 그린 그림 **124장**의 지시문이다. 한 장에는 그림이 4개(2병과 × 대기·공격) 들어 있다.

| 순서 | 묶음 | 장수 | 급한 정도 |
|---|---|---|---|
| 1 | 공군 기본 3장, 의경 기본 3장 | 6 | **가장 급함** — 지금 공군·의경만 이전 그림체다 |
| 2 | 적·보스 2장, 타이틀 1장 | 3 | 급함 — 5~10지역 보스와 타이틀이 이전 그림체다 |
| 3 | 계급대 그림 (군별 × 부사관·위관·영관·장성) | 115 | 천천히 — 없어도 게임은 된다 |

> Claude Code도 Figma 한도가 풀리는 매일 오전 9시 10분(한국 시각)에 **앞 번호부터** 이어서 그린다.
> 겹치지 않게 하려면 계급대 그림은 **뒤에서부터**(의경 → 공군 → 특공대 …) 만들면 된다. 한 묶음(5장)은 끝까지 같은 곳에서 만든다.

## 파일
- `prompts.html` — **이것을 브라우저로 연다.** 지시문 복사 버튼, 파일 이름 복사 버튼, 끝낸 것 체크가 있다.
- `prompts.md` — 같은 내용의 글 문서.
- `checklist.txt` — 만들어야 할 파일 이름 목록.
- `reference/` — 이미 만든 그림. 그림체를 맞추려고 함께 올리는 참고 그림.

## 하는 순서
1. 젠스파크에서 그림 생성을 열고 모델을 **GPT Image 2**(가장 최신 GPT 이미지 모델)로, 비율을 **1:1**로 고른다. (타이틀 한 장만 세로 2:3)
2. 새 대화마다 맨 처음에 아래 "처음에 붙여 넣는 말"을 보내고, 묶음 제목 아래 적힌 **참고 그림**을 함께 올린다.
3. `prompts.html`에서 **지시문 복사** → 붙여 넣기 → 생성.
4. 나온 그림을 내려받아 **파일 이름 복사**로 복사한 이름 그대로 저장한다. (예: `sheet_air_inf-art__inf-med.png`)
5. 계급대 묶음(5장)은 **첫 장이 잘 나오면 그 그림을 참고로 올리고** 나머지 4장을 만든다. 그래야 5장의 얼굴·옷이 같다.
6. 묶음이 끝나면 zip으로 묶어 Claude Code 대화에 올린다. 일부만 끝나도 올려도 된다.

## 처음에 붙여 넣는 말
```
I'm making sprite sheets for my own original mobile game. The attached images show the exact art style I need: soft hand-drawn storybook chibi, thin dark brown outlines, gentle watercolor shading, rosy cheeks. I will send prompts one at a time. For each prompt create exactly ONE square image that follows the prompt literally: a clean 2x2 grid of four separate figures with wide empty gaps, plain pure white background, no text, no labels, no borders. Match the attached art style and character proportions exactly. Do not copy the attached characters' outfits unless the prompt says so. Do not add explanations.
```

## 받을 때 확인
- 그림 4개가 2×2로 **서로 떨어져** 있다(왼쪽 대기, 오른쪽 공격). 서로 붙거나 가운데 선을 넘으면 다시 만든다.
- 배경은 흰색(또는 투명). 글자·화살표·테두리·이름표가 없다.
- 실제 군·경찰 휘장, 국기, 글자가 없다.
- 그림체가 참고 그림과 같다(가는 갈색 선, 수채 느낌, 볼터치). 굵은 검은 선이나 3D 느낌이면 다시 만든다.
- 같은 묶음 5장의 얼굴·모자·옷이 같다.
- PNG가 좋지만 JPG·WebP로 받아도 된다. 크기는 1024×1024 이상이면 된다.

## 올려 준 뒤
자르기(그림 4개로), 배경 정리, 크기 맞춤, 게임 적용, 배포는 Claude Code가 한다(`python3 -I tools/apply_soft.py`).
한 군별·계급대의 5장이 모두 모여야 게임에 들어간다.
